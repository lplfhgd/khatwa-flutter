# خطوة | Khatwa — Flutter Starter (المرحلة الأولى)

هذا مشروع Flutter أولي حقيقي (وليس صورة). يبدأ بصفحة اختيار المستخدم، ويضم مسار ولي الأمر ومسار الطفل في **تطبيق واحد**.

## المضمن في هذه النسخة
- تصميم RTL عربي وألوان Design Tokens المعتمدة.
- ملف صورة الشعار الأصلي المرسل من المستخدم: `assets/images/khatwa_logo.png`.
- اختيار «ولي الأمر» أو «الطفل» عند فتح التطبيق.
- ولي الأمر: لوحة رئيسية، إدارة بطاقات التواصل AAC (إضافة نص بطاقة)، روتين مصور قابل للتعديل، تقارير تجريبية، إعدادات أولية، صفحة رمز ربط توضيحي.
- الطفل: دخول بكود تجريبي، واجهة رئيسية، بطاقات AAC، روتين يومي، لعبة الألوان، قصة مصورة نصية أولية.
- اشتراك المسارين في حالة بيانات **محلية داخل تشغيل التطبيق الواحد** فقط؛ لا يوجد اتصال بين هاتفين بعد.

## التشغيل (Windows + VS Code)
1. ثبّت Flutter SDK وتأكد من `flutter doctor`.
2. افتح Terminal في مجلد المشروع، ثم نفّذ:

```bash
flutter pub get
flutter run
```

إذا لم يكن مجلد منصات Android موجودًا (لأن هذا حزمة مصدر مصغرة)، نفّذ مرة واحدة قبل `flutter pub get`:

```bash
flutter create --platforms=android .
```

يمكن أيضًا البدء بـ `flutter create khatwa` ثم استبدال `lib/` و`pubspec.yaml` ونسخ `assets/` من هذه الحزمة.

## بيانات تجريبية
- رمز دخول الطفل **482916**: للعرض فقط، غير آمن وغير متصل بأي خادم.
- لا يوجد تسجيل حقيقي أو تسجيل دخول أو حفظ دائم أو Firebase أو مزامنة متعددة الأجهزة.
- عند إغلاق التطبيق بالكامل قد تضيع التعديلات التجريبية.
- الضغط على بطاقة AAC يظهر رسالة نصية فقط؛ **لم يتم تنفيذ Text-to-Speech بعد**.
- خيار «ولي الأمر» في هذه النسخة لا يمنح حماية صلاحيات؛ يجب تنفيذ Firebase Auth، قواعد Firestore، جلسة طفل مقيّدة، وموافقة ولي الأمر قبل إطلاق نسخة فعلية.
- تصميم الشعار في الأصل يحتوي على كتابة وهوية كاملة؛ داخل الواجهات يمكن لاحقًا توليد نسخ منفصلة (أيقونة صغيرة/نسخة كاملة) من الملف الأصلي بدون إعادة رسمه.
- الخط المعتمد **IBM Plex Sans Arabic** مذكور بالاسم في `ThemeData` لكنه **غير مضمن في الملفات**؛ يجب إضافة ملفات مرخّصة إلى مشروعك وتسجيلها ضمن `pubspec.yaml` ليظهر بشكل مضمون على الأجهزة.

## المراحل التالية
1. إضافة Firebase Auth (ولي الأمر فقط) وإنشاء ملفات الأطفال.
2. تصميم Firestore Schema وقواعد الأمان، وربط طفل برمز/QR مؤقت وموافقة صريحة.
3. تخزين محلي مضبوط للعمل دون اتصال، وتزامن آمن.
4. رفع الصور وتفعيل TTS لبطاقات AAC؛ لا يُمنع التواصل دون إنترنت.
5. إكمال بقية شاشات ولي الأمر والطفل، وإتاحة ضبط التفضيلات الحسية.
6. اختبارات واجهة/وحدة واختبارات أمان ومستخدمين.
